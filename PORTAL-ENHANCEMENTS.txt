5th-5M Portal - Premium UI & Student Portal & CR Management Update

What was added without removing existing functionality:
- Premium responsive UI polish across the portal.
- CR-managed portal logo: upload an image or paste a logo URL in CR Portal > Settings. The same logo appears in Student Portal.
- Today and Tomorrow timetable preview on Student Portal.
- CR Timetable Manager has quick Today/Tomorrow controls; the existing full-week timetable management remains unchanged.
- Student Feedback manager in CR Portal for discussion posts and reported issues, including issue status management and removal.
- Personalized student dashboard / welcome card.
- Notification center from announcements, assignments and exams.
- Today's classes and next-class countdown.
- Assignment tracker for pending/overdue assignments.
- Exam countdown.
- Attendance calculator.
- Subject dashboard with teacher and attendance information.
- Class discussion / Q&A.
- Student issue reporting.
- Student profile API (/api/me).
- Existing Class Hub, polls/vote records, assignments, exams, study materials, photo slider, attendance, reports, leaderboard and student tools remain available.

Database additions:
- Settings.portalLogoUrl (nullable)
- DiscussionPost
- StudentIssue

Deployment note:
Keep your existing .env / DATABASE_URL. Never commit .env.

After replacing/updating the project against the same live DATABASE_URL, run:
  npx prisma db push
  npx prisma generate
  npm run build

Then commit and push to GitHub so Vercel can deploy the fixed version.
