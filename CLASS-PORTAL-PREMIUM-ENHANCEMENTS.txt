CLASS PORTAL — PREMIUM UI & PRODUCTIVITY ENHANCEMENTS

This update adds a CR workspace quick-navigation launcher and extra visual polish.

NEW PRODUCTIVITY FEATURE
- Quick jump button in the CR top bar.
- Ctrl+K / Cmd+K keyboard shortcut to open quick navigation.
- Searchable destinations across dashboard, attendance, students, subjects, timetable, class hub, feedback, photos, analytics, requests, QR attendance, reports, audit log, backup, and settings.
- Escape key closes the launcher; clicking the backdrop closes it.
- Responsive layout, focusable controls, reduced-motion support, and keyboard-friendly navigation.

VISUAL POLISH
- Refined command launcher with translucent surface, subtle motion, responsive sizing, and clear empty state.
- Improved hover/focus behavior for navigation and dashboard cards.
- No database schema or attendance record changes are included in this enhancement.

DEPLOYMENT SAFETY
- Keep the existing DATABASE_URL and production database.
- Do not run prisma migrate reset or destructive database commands.
- Install dependencies and run npm run build before deploying. This source update has not been verified with a full production build in this environment.
